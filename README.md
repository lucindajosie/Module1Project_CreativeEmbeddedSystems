🌊 Display a line drawing of a wave (followed by a small trail of shadows) bouncing off the edges of a picture of the beach 🌊

## Components
* ESP32
* Arduino IDE
* Arduino C++
* TFT_eSPI library

## Setup
* Clone this repository onto your computer using:
```
git clone https://github.com/lucindajosie/Module1Project_CreativeEmbeddedSystems
cd Module1Project_CreativeEmbeddedSystems
```
* Then open wave.ino in Arduino IDE:
```
open wave.ino
```
* Go to Library Manager (Tools > Manage Library) then search for and install ```tft_espi```
* Connect your ESP32 to your computer with a usb-c cable
* Select your board (Tools > Boards > esp32 > ESP32 Dev Module)
* Select your port (Tools > Port > _your_port_)
* Press Upload in the top left corner
